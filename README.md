# Open Source Contributions

[![OpenSource](https://img.shields.io/badge/Open%20Source-%E2%9D%A4%EF%B8%8F-%23E24329?logo=opensourceinitiative)]()
[![Status](https://img.shields.io/badge/Status-Active-orange)]()
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

開源專案貢獻的記錄倉庫，收錄參與的 PR、補丁與社群回饋，作為長期參與開放原始碼社群的累積。

## 狀態

> **持續更新中**：貢獻記錄將陸續補上。

## 內容規劃

| 類別 | 說明 |
|------|------|
| Pull Requests | 已提交的 PR 與對應專案、內容說明 |
| 補丁集合 | 修復 bug、改進文件等小型貢獻 |
| 議題參與 | Issue 回報與討論紀錄 |
| 心得整理 | 貢獻流程、程式碼審查的學習筆記 |

## 參與原則

- 從文件與小型 bug 開始，逐步累積對專案的了解
- 遵守各專案的貢獻規範（CONTRIBUTING）
- 記錄每次貢獻，形成可追蹤的歷程

## 目錄結構

```
opensource-contributions/
├── pull-requests/  # PR 記錄
├── patches/        # 補丁與 diff
├── notes/          # 貢獻心得
└── README.md
```
